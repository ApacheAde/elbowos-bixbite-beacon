# Bixbite Beacon

Full-colour Python 3 neon lighthouse-sweep arcade for [ElbowOS](https://x.com/ElbowOS).

Aim the raspberry lantern and sweep gold moths plus cyan buoys. Violet storm bats break the chain. Left / Right (or A / D) spin the beam. Space / W / Up pulses reach.

## Play

```bash
pip install -r requirements.txt
python3 bixbite_beacon.py --play
```

## Record a 9:16 reel

```bash
python3 bixbite_beacon.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
